# SauceDemo Playwright Project

This is my final project for the Playwright Automation course.

## Setup
1. Clone the repo
2. Run `npm install`
3. Run `npx playwright install`

## Running Tests
- Run all tests: `npx playwright test`
- Run in UI mode: `npx playwright test --ui`

## Scenarios Covered
- Successful login with valid credentials
- Error validation for locked-out users
- Full checkout journey (E2E)
